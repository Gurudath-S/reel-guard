# Activities, service status and settings

**Dependencies.** Use platform Activity, XML layouts, TextView, EditText, Spinner or RadioGroup, Switch, Button, ListView and TimePickerDialog. Use MainActivity for dashboard and an inline limit editor, WhitelistActivity for membership, and a debug-variant Activity for diagnostics. All reads and edits go through the repository. Bind returned immutable state on the main thread.

## MainActivity and service status

| Method or action | Flow and observable result |
|---|---|
| onCreate / onStart / onResume | Inflate controls once, restore draft values and selected scope, subscribe to repository updates while started, refresh on return from system settings. Show the current window's local reset time, combined usage and rows for Reels tab, feed videos and Shorts. Each row shows eligible count and time. Show exempt visits/time separately. |
| readServiceStatus() | Use AccessibilityManager.getEnabledAccessibilityServiceList with all feedback types and compare the component's package/class. Combine the system result with the service's in-process connection flag. Render Disabled, Enabled / waiting for connection, or Connected. Show storage/selector problems separately. |
| openAccessibilitySettings() | Explain that ReelGuard reads the two target apps' visible content to recognize reels and may navigate Back/Home at the limit. Launch Settings.ACTION_ACCESSIBILITY_SETTINGS from the Activity. Show manual navigation instructions if the device cannot resolve it. After return, derive status again. |
| render(snapshot) | Map stable surface codes to localized labels. Use exact counts and formatted elapsed minutes/seconds. For a combined cap, display the combined denominator once. For separate mode, show the configured cap on its row. Show “No limit” for disabled measures. A refresh must preserve unsaved editor input. |
| onStop / onSaveInstanceState | Unsubscribe, cancel UI callbacks and retain only the draft and navigation state. On recreation reload authoritative values and show the draft until Save or Cancel. |

## Limit editor

| Action | Contract |
|---|---|
| openEditor / selectScope | Populate a draft from the saved settings. Combined mode edits one cap pair. Separate mode exposes all three pairs. Each measure has an enable control and integer input. Preserve inactive pairs when switching. |
| validateDraft | Enforce [storage bounds](10-data.md). Blank enabled fields, fractional values, overflow and malformed numbers produce field-level errors and retain input. Disable both caps deliberately to track usage without enforcement. |
| saveDraft / cancelDraft | Provide dwell vs every swipe, dwell seconds, warning percentage and local reset time. Save the entire valid draft atomically. Show the effective next reset if its time was edited. Lowering or increasing an active limit reevaluates today's totals immediately. Cancel restores committed settings. |
| Optional delay before increasing limits | If implementing the plan's friction option, start a 30 s monotonic countdown for an edit that weakens an active cap (including disabling it). Hold the draft uncommitted, display remaining seconds, and require a final confirmation after expiry. Cancel on leaving the editor. Baseline ships immediate edits and no temporary override. |

## WhitelistActivity

| Method or action | Flow |
|---|---|
| loadLists() | Display saved entries by platform then canonical handle, and recent creators newest first. Give clear empty states. Disable quick add for existing members. |
| addTyped(platform, text) | Show platform chooser and handle field. Normalize/validate through CreatorKey.parse. Show a field error for invalid input, “Already added” for duplicates, and clear the field only after a successful add. |
| addRecent(key), remove(key) | Apply the canonical key to WhitelistStore. Refresh both lists after commit and publish the membership revision to the running service. Removing from membership preserves the recent-creator entry. |

**Other navigation.** The dashboard surfaces a selector-health notice even with notifications denied. Request notification permission from the Activity with a user-visible explanation when enabling alerts on API 33+. Show debug navigation only in debug builds. Include readable labels for icon controls, platform-specific handle examples, accessible focus order, scrollable content at large fonts and theme-aware colors.

**Acceptance.** Walk from a fresh install through enabling the service, setting a combined quota of 3, reaching it, editing a separate cap, quick-adding a seen creator and removing it. Rotate while entering an invalid number. The draft survives, the cap is unchanged until Save, and status refreshes after system settings. Relaunch after Reels and Shorts usage and compare all dashboard values to database aggregates.
